# Docnlab: сайт и обновление данных

Публичное превью: https://dilemion.github.io/doctor-lab-preview/

Каталог содержит актуальный снимок московских цен ДНКома. Цены подтверждены для Docnlab; скидки не применяются повторно. Описания и подготовка сохраняются из карточек лаборатории, постепенно дополняются и обновляются.

Пять направлений дизайна доступны в `variants/`. Рабочий каталог — `analyses/`. Общая логика и стили — `site/`, опубликованные снимки — `data/`.

Ежедневный workflow `Daily Docnlab data` обновляет цены около 06:17 по Москве и публикует проверенный экспорт в существующую ветку `gh-pages`. Возможен ручной запуск через GitHub Actions. При сбое последняя успешная публикация сохраняется.

Редактируемый контент приходит из закрытой Google Sheets. В публичном репозитории нет OAuth-токенов и редакторских черновиков. Для серверного чтения поддержаны variables `DOCNLAB_SHEET_ID` и secret `GOOGLE_SERVICE_ACCOUNT_JSON` для отдельного read-only аккаунта. Пока контент синхронизируется локально через существующий доступ владельца.

Установка: `python -m pip install -r scripts/requirements.txt`. Проверка: `python -m unittest discover -s tests -p 'test_*.py'` и `node site/data.test.cjs`. Сборка: `python scripts/build_site.py --output _site`. Локальный просмотр: `python -m http.server 8765`.

Синтетические тестовые фикстуры в `tests/fixtures/` содержат выдуманные данные. Они не входят в публичный сайт.
