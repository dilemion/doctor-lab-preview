# Основной дизайн и поиск анализов

Пользователь выбрал вариант 1 «Лаборатория» основным 13.10.2026. Главная `/` использует его; пять вариантов доступны в `/variants/`.

Поиск ориентирован на названия и сокращения из назначения. В интерфейсе нет предложений искать по коду. Технический поиск по точному коду сохраняет ведущие нули и суффиксы; неизвестный полный код не подменяется. Точное сокращение из исходного названия ранжируется выше случайного начала слова. Буквы витаминов сравниваются в витаминном контексте. Возможная опечатка явно помечается как предположение.

Каталог показывает подтверждённые цены и скидки из публичного снимка, срок, биоматериал, варианты и цену забора при наличии данных, описание и подготовку или ссылку на источник. Фильтры: отдельные анализы/комплексы, скидки; сортировка по соответствию, цене или названию. По 20 результатов на странице. URL хранит запрос и фильтры. После явного поиска фокус переходит к результатам; во время ввода остаётся в поле.

Список для визита хранит до 100 уникальных кодов только в sessionStorage текущей вкладки. Текущие цены читаются из снимка; скидка не применяется повторно. Забор не добавляется автоматически. Если он выбран явно, сумма и копируемый текст указывают, что он уже включён. Недоступные сохранённые коды остаются видимыми, сумма показана неполной, копирование блокируется до явного удаления. Реальной записи и оформления заказа этот список не создаёт.

Ежедневные обновления цен и Google Sheets остаются приостановлены по просьбе пользователя. Дата прайса показана в каталоге; старый снимок получает предупреждение. Эта UI-правка расписания не возобновляет.

Проверки: `python -m unittest discover -s tests -p 'test_*.py'`, `node --test site/*.test.cjs`, `python scripts/build_site.py --output <new-directory>`. Визуальные материалы и краткие записи проверки лежат в `.design/analyses-search/`; экспорт сайта их исключает.
